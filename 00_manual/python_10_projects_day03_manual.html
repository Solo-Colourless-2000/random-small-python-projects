04 · Pythonの基礎：今日使う仕組み

ここでは今日のコードに実際に出る仕組みだけを扱います。新しい用語は作品の具体例でも説明します。名前への代入は値をその名前へ結び付ける操作です。常に独立したコピーを作るわけではありません。

型今日の具体例区別する点
str"13", "00100"文字列。lenはPythonの文字数で、UTF-8のバイト数や端末の表示幅とは別です。
int13, 0, -99整数。Cの固定幅整数のような桁あふれとは違います。教材では長さ・値を制限します。
boolTrue, False条件の値。JSONのtrue/falseを読むとこの型です。
list[1, 4, 4], []順番があり変更できる容器。空リストはifで偽です。
tuple(sys.argv[1], sys.argv[3])順番のある組。ここでは左・右の2入力をまとめます。
dict{ ")": "(" }キーと値の対応。キーで値を取り出します。
set{"name", "done"}重複を持たない集合。キーの過不足を判定します。
dequequeue = deque()左右から取り出せる容器。作品08は先入れ先出しです。
FractionFraction("1/3")整数比を保つ分数。今日の基本実習はfloatを使いません。

=は代入、==は値の等価比較、!=は等しくない比較です。isは同一オブジェクトかの判定であり、数値や文字列の等価比較に使いません。notは真偽を反転します。andは左が偽なら右を評価せず、orは左が真なら右を評価しません。andとorは一般にはboolそのものに限らず、選んだオペランドを返します。今日の条件文ではその真偽を判断します。

defは関数を定義します。関数名に()を付けると呼び出しです。mainという名前は慣習であり、特別に自動実行される機能ではありません。printは画面へ表示し、returnは関数の実行を終えて値を呼び出し元へ返します。呼び出したmainの整数をSystemExitへ渡すことで、OSへ終了ステータスを伝えます。

本書の規約は成功0、ファイルを利用できない・保存できない・対話の中断1、入力の個数・形式・範囲の問題2です。括弧の不一致やファイルの差分は道具が検査した結果であり、処理が完了すれば0です。エラー案内も本書のコードではstdoutへ表示し、想定内の失敗ではstderrは空です。

コロン:の後の字下げが処理の範囲を決めます。mainの中は4スペース、その中のifやforの本体はさらに4スペースです。forは要素を順番に処理し、whileは条件が真の間繰り返します。returnは関数全体を終えます。breakなら最も内側のループだけを終え、continueならそのループの次の周へ進みますが、今日の完成コードでは後者2つは使いません。

sys.argvは実行コマンドの引数を入れたリストです。[0]はスクリプト名、[1]からが利用者の引数で、基本はstrです。inputもstrを返します。"18"はstr、18はint、18.0はfloatです。数値変換の成功と値の範囲の検査は分けます。空文字""も1つの引数として渡せます。対話でEnterだけなら空文字、入力そのものが終わればEOFです。

添字は0から始まります。[-1]は末尾ですが空のリストでは失敗します。text[1:]は2文字目以降で、range(1, 3)は1と2を取り出し3を含みません。スライスの終点も通常は含みません。for number, item in enumerate(...)は2つの要素の組を2つの名前で受け取るアンパックです。

stripは前後の空白を除いた新しい文字列を返し、途中の空白は残します。lowerも元の文字列を変更せず小文字の新しい値を返します。split(",")は空の項目を保持しますが、引数なしのsplit()は連続する空白をまとめ、前後の空白を捨てます。joinは容器を変更せず、要素をつないだ文字列を返します。append・extend・pop・popleftは容器を変更します。

any(ch not in ALLOWED for ch in name)の括弧内はジェネレーター式です。普通のforに読み替えるなら、まずinvalidをFalseにし、nameの各chを見て、許可外の文字があればinvalidをTrueにする処理です。anyは真になる要素を見つけると検査を止めます。リストを丸ごと先に作る必要はありません。

mark = "x" if task["done"] else " "は条件式です。普通のifなら、doneが真の枝でmarkへ"x"、elseの枝で空白を代入する2通りの処理です。print("Merged:", *merged)の*は引数の展開で、リストの値を順番に個別の引数としてprintへ渡します。ここではprintが間に空白を入れて最後に改行します。

整数の+は加算、文字列の+は連結です。/は通常の割り算で、int同士ならfloatになりますが、作品09はFraction同士の/なので結果もFractionです。テストの独立モデルで使う%は余りです。今日の完成コードは//を使いません。ビット演算の&と<<は作品01で具体値を追います。

tryの範囲で起きた想定する例外だけをexceptで扱います。ValueErrorは変換や内容の問題、OSErrorはファイルを利用できない問題です。UnicodeErrorは文字コードの問題です。例外の型を限定し、無条件のexceptで誤り全体を隠しません。Pathは場所を表し、openで初めて読み書きを始めます。withでクローズしても、排他的作成や原子的な保存とは別です。

補強解説：なぜ右端からビット0なのか

補強解説：整列済みという前提条件を守る

leftとrightは最初から小さい順に並んでいる必要があります。iは左側で次に取り出す位置、jは右側で次に取り出す位置です。両方に値が残る間だけ先頭同士を比べ、小さい方をmergedへ追加します。

追加の詳説：JSONを検査してから保存する理由

import sys


def main():
    pairs = {")": "(", "]": "["}
    if len(sys.argv) != 2:
        print("Usage: python3 04_bracket_checker.py brackets")
        return 2
    text = sys.argv[1]

        if symbol not in "()[]":
            print("Error: use ()[] only.")
            return 2
    stack = []
    for position, symbol in enumerate(text, 1):
        if symbol in "([":
            stack.append(symbol)
        else:
            if not stack or stack[-1] != pairs[symbol]:
                print(f"Mismatch at {position}")
                return 0
            stack.pop()
    if stack:
        print("Unclosed")
    else:
        print("Balanced")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

        if left[i] <= right[j]:
            merged.append(left[i])
            i += 1
        else:
            merged.append(right[j])
            j += 1
    merged.extend(left[i:])
    merged.extend(right[j:])
    print("Merged:", *merged)
    return 0

import json

import sys
from pathlib import Path

ALLOWED = string.ascii_letters + string.digits + " -"


def main():

        print("Usage: python3 07_json_checklist.py input.json output.md")
        return 2
    try:
        with Path(sys.argv[1]).open("r", encoding="utf-8") as stream:
            text = stream.read(4097)
        if len(text) > 4096:
            raise ValueError
        tasks = json.loads(text)

        print("Error: cannot read the UTF-8 input.")
        return 1

        print("Error: use valid JSON within 4096 characters.")

            print("Error: each task needs name and done only.")
            return 2
        name = task["name"]
        if not isinstance(name, str) or not 1 <= len(name) <= 30:
            print("Error: name needs 1-30 characters.")
            return 2
        if not name.strip() or any(ch not in ALLOWED for ch in name):
            print("Error: name needs ASCII letters, digits, spaces or hyphens.")
            return 2

            return 2

    except OSError:
        print("Error: cannot create output; choose a new path.")
        return 1
    print(f"Saved: {sys.argv[2]}")
    return 0


if __name__ == "__main__":
