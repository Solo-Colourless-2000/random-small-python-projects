## 教材用の限界

CookieとHTTPヘッダーの解析は完全なブラウザー評価ではない。ファイアウォールのルール一覧は実通信の可否を決めない。IOC一致は侵害の証明ではない。ファイルハッシュ比較は原子的なスナップショットを保証しない。メールのヘッダー解析は認証ヘッダーの真正性やSPF・DKIM・DMARCの検証を行わない。ログイン試行制限はローカルの模擬モデルで、実際のアカウント・認証サーバー・分散攻撃は対象外。実データや実システムへ適用するための監査ツールとして利用しない。
