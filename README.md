# Small Python Projects for Beginners

A collection of small Python projects for myself learning python programming.

The projects cover some simple stuff such as file handling, networking, basic utilities.

I used ChatGPT to create the project source files and the manual files (in Japanese) to learn.
Feel free to use them if you want.

## How to Run

Make sure Python 3 is installed.
Run a script from the project directory:

```bash
python3 <filename>
```

Some scripts require command-line arguments or user input.
